# 🌦️ Smart Weather Forecast App

A modern weather forecasting application built with **Python** and **Streamlit** that provides real-time weather information, environmental insights, and activity recommendations through a clean and premium user interface.

## 🚀 Features

### 🌍 Real-Time Weather Information
- Current temperature
- Weather condition
- Humidity
- Wind speed
- Visibility
- Feels-like temperature

### 📅 5-Day Weather Forecast
- Detailed weather predictions for the next 5 days
- Temperature trends
- Weather condition tracking

### 🌫️ Air Quality Index (AQI)
- Real-time AQI monitoring
- Air quality status and recommendations
- Health awareness insights

### 🌅 Sunrise & Sunset Information
- Daily sunrise time
- Daily sunset time
- Better planning for outdoor activities

### 🦟 Mosquito Alert System
- Weather-based mosquito activity prediction
- Helps users stay prepared during high-risk conditions

### ⚽ Outdoor Sports Recommendation
- Checks weather suitability for outdoor sports and activities
- Provides activity recommendations based on current conditions

### 🌌 Stargazing Conditions
- Evaluates weather conditions for stargazing
- Indicates visibility and sky clarity

### 🚨 Natural Weather Alerts
- Heatwave alerts
- Extreme weather notifications
- User safety recommendations

### 🎨 Premium User Interface
- Built using Streamlit
- Modern and responsive design
- User-friendly experience
- Clean dashboard layout

This project goes beyond a traditional weather application by combining:

- Weather Forecasting

The goal was to create a weather assistant that not only displays weather data but also helps users make informed daily decisions.
